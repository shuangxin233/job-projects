# 问题解决记录

日期：2026-09-07。记录本次实际实现选择与验证，不包含未经验证的性能或效果指标。

| 问题 | 处理 | 如何验证 |
| --- | --- | --- |
| 用户希望简单、能够理解 | 使用标准库 CLI，拆成六个职责清楚的模块，不引入 Agent 框架 | 检查导入，按 README 启动；面试讲解对应实际代码 |
| 怎样确保模型基于 Schema 自主选工具 | 每次 API 请求传入 Registry 导出的 tools，设置 auto；解析原生 tool_calls | HTTP 请求单元测试；真实模型能力另由 live_smoke 验证 |
| 工具执行后模型不知道结果 | 保存 assistant 调用，再追加匹配 call_id 的 tool 结果并继续 loop | 断言第二次模型请求中的结果值与 call_id |
| 同一用户两个窗口串状态 | 使用 `(user, session)` 生成独立数据库；待办也放在 session 状态内 | A/w1、A/w2、B/w1 三组隔离及重启测试 |
| 两个进程同时写相同会话 | 每会话 SQLite 事务锁；其他会话使用不同文件 | 同会话忙、不同会话仍可访问测试 |
| 历史太长和工具消息被截断 | 最近四轮 + 有界摘要；只移除完整轮次；当前轮次超限明确停止 | 压缩后待办召回、无孤立 tool 消息、预算停止测试 |
| 模型或工具错误可能导致死循环 | 最大六次模型决策；参数错误作为 tool 错误回填；API 有界重试 | 未知工具、非法 JSON、除零、解析修复、轮次上限等测试 |
| 解析器收到 message=null 抛出 AttributeError | 首次测试暴露缺少类型检查；增加 message 必须为 dict 的检查 | 同一异常测试重跑，确认转为可恢复 ParseError |
| “思考过程”容易实现成冗长或不可用字段 | 只提取模型可展示的一句话 reason，核心控制用 tool_calls | 解析 reason 与普通文本的测试；文档说明语义边界 |
| 已完成待办后 LLM 失败 | 正常错误返回也保存会话事务，向用户说明已完成操作保留 | 先 add 再模拟 API 超时，检查待办仍在 |
| 自动化测试不能证明真实 API 可用 | 确定性测试和 live_smoke 分开；真实 API 无密钥时明确失败 | TEST_REPORT 如实记录执行状态，不用替身冒充真实调用 |
| DeepSeek 当前默认开启深度思考，需要回传 reasoning 字段 | 核对官方文档后使用 deepseek-v4-flash，并显式关闭 thinking，维持简单的普通工具调用协议 | 测试官方地址带 disabled 参数、其他服务不发送此扩展；真实效果仍需密钥验证 |
| 上传代码时不能带入本地密钥、聊天数据 | .gitignore 忽略 .env 和运行数据；打包按源文件清单进行 | 上传前检查 git 暂存文件，最终包不包含 .env 或数据库 |
| Windows PowerShell 读取中文路径与失败退出码 | 启动脚本保存为 UTF-8 BOM，并传递 Python 的退出码 | 实际运行启动脚本，缺密钥时正确提示并返回退出码 1 |
| 实际 DeepSeek 请求返回 HTTP 402，后续用例仍继续请求 | 查官方错误码及余额 API 确认余额不足；增加明确充值提示，冒烟测试遇到 API 错误即停止并记录跳过数 | 本地保存真实失败记录，新增 402 不重试、冒烟停止两个确定性测试；余额恢复前不再重复请求 |
| 用户希望使用免费真实 API | 核对 Groq Free 套餐、Qwen 工具调用及兼容接口；默认配置改为 Groq，旧 DeepSeek 密钥只在本地备份，未转发给 Groq | 新增默认服务、输出限制、Retry-After 和较长限流停止测试；免费模型真实验证等待 Groq Key |

## 仍保留的简单边界

- 摘要是截取式压缩，不做向量检索或语义排序；很久以前的闲聊信息可能丢失。
- API 接口限兼容 Chat Completions/function calling 的模型，不自动切换到 Responses。
- search/weather 是明确标注的 mock，todo 和 calculator 是本地真实执行。
- 命令行用户 ID 不提供认证；整个项目面向本机面试演示。
- 强制退出会回滚当前轮次；日志在正常轮次结束时提交，没有实现进程崩溃恢复日志。

实际测试结果见 `TEST_REPORT.md`，可执行的真实 API 用例见 `scripts/live_smoke.py`。

## Groq 访问受阻后的替代方案

用户登录页显示 Forbidden，本机未认证请求也返回 403。未推断具体封禁原因；核对智谱官方资料后默认改用免费 glm-4.7-flash。智谱官网 HTTP 200、未认证 API HTTP 401；新增智谱请求参数测试后共 37 项通过，真实联调仍等待智谱 Key。
